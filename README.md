# The Akita Project --
This project is a window into the Okordia (Akita) people of the Ijaw tribe in Bayelsa state of Nigeria.
The project reveals the Okordia people in on two(2) perspectives:
## 1. the general cultural perpectives - includes festivals, history, foods, beliefs and more
## 2. the akita language perspectives - orthography, Akita-English translation dictionary, grammar and other lingustic features of the language.
